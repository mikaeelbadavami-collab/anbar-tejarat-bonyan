# انبار تجارت بنیان

نسخه آفلاین اولیه Android با رابط فارسی/RTL و مسیر Build خودکار GitHub Actions.

## Build در GitHub

Workflow: `.github/workflows/build-apk.yml`

1. Repository را باز کنید.
2. Actions → Build Android APK.
3. Run workflow را اجرا کنید.
4. پس از سبز شدن اجرا، Artifact با نام `anbar-tejarat-bonyan-debug-apk` را دانلود کنید.

## شناسه برنامه

`com.tejaratbonyan.anbar`
